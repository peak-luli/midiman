One stack, set once on body: 14px/1.45 ui-sans-serif, system-ui, sans-serif. Seven sizes, three weights, one uppercase label, and a monospace face reserved for numbers that change while you watch them. A button now takes the page font too, in a fixed 13/16 line box — which is what makes every control in the bar exactly 30px tall.

Two rules, and they are different rules. tabular-nums goes on every number, so digits share a width; --mono goes only on a number that is changing in front of you — a readout, a key cap, a lane state, a live score. A number that merely sits there (#info b, a bar count in a hint) stays in the page font. Both are only half the fix: a tabular readout with no min-width still moves the row when the text gets longer, which is why #pos, #played, #speed b and .lst each reserve one.
The button rule, and why it is a type rule
13/16the glyph is a triangle, the box is 16px, the button is 30px
13/16the glyph is a circle, one pixel shorter — the box is still 16px, the button is still 30px
15/16a bigger glyph in the same line box: wider padding, same height
Out:
12/16smaller type, same line box, plus the strip's own border — 30px again
Fixing the line box is what makes the row level. With line-height:normal a button measured its tallest glyph, so ▶ Play came out 30px and ● Click 29px beside it. Naming the line 16px takes the glyph out of the arithmetic: 16 + 6 + 6 + 2 = 30, whatever is printed on it.

Rules. One family, named once on body and repeated on button because a control will not inherit it. Sizes come from the seven — 10 label, 11 fine, 12 control and secondary, 13 button, 14 body, 15 title, 26 overlay — and a new element takes the one that matches its role, not a new number in between. Weight has three values and each means something: 500 is the plate that names a control, 600 is an on-state, 700 is a title or a readout; everything else is 400 and emphasis is done with colour, not weight. A section heading is 10px uppercase at .08em in --dim with air under it and no rule. Every number is tabular-nums; a number that changes while you watch also takes --mono and a min-width, because tabular figures keep the digits aligned but only a reserved width keeps the row from moving. Line height is 1.45 for prose and a fixed 16px inside any control, so type never decides how tall a control is.
